# Contributing to OpenEval

Thank you for your interest in contributing to OpenEval! This project is open source under the **GPLv3** license and welcomes contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a feature branch: `git checkout -b feature/amazing-feature`
4. Make your changes
5. Run tests: `flutter test`
6. Commit your changes: `git commit -m 'Add amazing feature'`
7. Push to your branch: `git push origin feature/amazing-feature`
8. Open a Pull Request

## Code Style

- Follow Dart's official style guidelines
- Use meaningful variable and function names
- Add comments where necessary
- Ensure all code passes `flutter analyze`
- Write tests for new features
